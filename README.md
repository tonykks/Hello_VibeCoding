# Hello VibeCoding Web App

간단한 인사 페이지를 만드는 학습용 웹앱입니다.  
HTML, CSS, JavaScript만으로 구성되어 있으며, 입력/저장/테마 전환 같은 기본적인 프론트엔드 기능을 담고 있습니다.

## 주요 기능

- **인사말 변경**
  - 이름을 입력하고 `인사하기` 버튼을 누르면 인사 문구가 변경됩니다.
  - 이름 입력창에서 `Enter` 키로도 동작합니다.

- **실시간 현재 시간 표시**
  - 화면에 현재 시간을 표시하고 1초마다 업데이트합니다.

- **오늘의 목표 저장**
  - 목표 입력값을 `localStorage`에 자동 저장합니다.
  - 브라우저를 새로고침해도 이전 입력값이 유지됩니다.

- **다크모드 전환**
  - `Dark Mode / Light Mode` 버튼으로 테마를 전환할 수 있습니다.
  - 선택한 테마 상태를 `localStorage`에 저장해 다음 접속에도 유지합니다.

## 화면 구성

- 중앙 정렬 카드 UI
- 제목: `Hello VibeCoding`
- 설명 문구, 인사말, 이름 입력 영역
- 현재 시간 영역
- 오늘의 목표 입력 영역
- 테마 전환 버튼

## 프로젝트 구조

- `index.html`
  - 페이지 구조(마크업)와 동작 스크립트가 포함되어 있습니다.
  - 인사말 변경, 시계 업데이트, 로컬 저장, 테마 전환 로직을 처리합니다.

- `style.css`
  - 카드 레이아웃, 색상, 버튼/입력 스타일을 담당합니다.
  - 반응형 스타일(모바일 대응)과 다크모드 색상 테마를 포함합니다.

## 동작 방식(구현 포인트)

1. **인사말 변경**
   - 이름 입력값을 읽어 인사 문구 텍스트를 동적으로 변경합니다.

2. **실시간 시계**
   - `setInterval`로 1초마다 현재 시간을 업데이트합니다.

3. **입력값/테마 저장**
   - `localStorage` 키를 사용해 목표(`vibecoding_goal`)와 테마(`vibecoding_theme`)를 저장합니다.
   - 페이지 로드 시 저장된 값을 읽어 화면 상태를 복원합니다.

4. **다크모드**
   - `body`에 `dark` 클래스를 토글하고, CSS 변수로 테마 색상을 전환합니다.

## 실행 방법

1. 프로젝트 폴더에서 `index.html` 파일을 브라우저로 엽니다.
2. 이름 입력, 목표 입력, 다크모드 전환 기능이 정상 동작하는지 확인합니다.

## 사용 기술

- HTML5
- CSS3 (반응형, CSS 변수)
- Vanilla JavaScript (DOM, 이벤트, `localStorage`, 타이머)
